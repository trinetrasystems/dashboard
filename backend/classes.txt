# Trinetra Systems — perimeter image classes
# ────────────────────────────────────────────────────────────────────────────
# The DeepStream pipeline names every saved image <camera>_<class>_<time>.jpg with one of these classes,
# from where the detected object is (the regions drawn on the Alerts → Regions / DeepStream → Zones page):
#
#   Boundry-object   an object in an ALERT region (wall top, concertina, fence line)
#   outside-person   a person on the outside side of the perimeter line
#   outside-object   any other object on the outside side
#   zone-person      a person in a WATCH region (inside the line)
#   zone-object      any other object in a WATCH region
#
# Alerts are NOT decided by the class: the client's alert rules (Alerts page) read each frame's description
# (object kind, regions, outside / alert flags) — see backend/alert_rules.py.
# The Detection Log / Whitelist dropdowns list these classes plus the labels of the DeepStream model in use.
# Edit + refresh the browser — the file is read on every request, no restart.
