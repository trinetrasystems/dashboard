Whitelist
A whitelisted class or detector label never fires an alert rule (e.g. zone-object for a gate that is always parked in a watch region). Its images still go into the Detection Log.
how it works
From the moment a class is added here, new frames with it no longer count for any alert rule; alerts already raised stay in the alert history until acknowledged. Its presences show a WHITELIST tag on the Visits page. To stop one kind of alert only, switch that rule off on the Alerts page instead.
